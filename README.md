# 亚华 · 电量与电价96时段转24时段

在原“实际上网电量”网页中增加电价转换，侧栏切换两项功能。

## 使用

- **实际上网电量**：上传电厂侧日清分账单，定位“省内现货日内 → 实际上网电量”，每连续4点求和。原有识别、校验及下载功能保留。
- **电价（日前／实时）**：上传机组出清结果 `.xlsx`，每连续4个15分钟电价取算术平均。支持多文件，逐文件、日期、机组及市场选择查看和下载。

电价按表内日期处理，价格单位沿用原表，未标单位时不猜测。时间为结束时刻，00:15、00:30、00:45、01:00归入00:00—01:00，依次至24:00；也支持名为“时段”的1—96整数列。不同日期、机组及市场不混算。

价格为时间均价，不按电量加权，不对价格求和。0价、负价保留，空白不作为0。需要完整96点，缺点、重复点、无效价格或日期会停止该文件的计算并报错。表头可移动、列可重排，在前100行、前512列内识别。公式单元格需由Excel保存计算缓存。

电价Excel包含24时段电价、原始96点电价、来源单元格以及全天时间均价核对。使用AVERAGE公式，写入计算缓存。显示4位小数，计算保留原始精度。

## 更新已有网页

已有仓库：`tyrellli/yahua-actual-energy96TO24`，入口仍为 `app.py`。

将本文件夹内的 `app.py`、`price.py`、`README.md`、`test_price.py` 上传到原仓库根目录并提交。已有的 `energy.py`、`test_energy.py`、`requirements.txt` 无须修改，本包也包含这些文件，方便完整部署。只上传程序文件，不上传账单、出清表或本机缓存。

原网页若仍连接该仓库的main分支，提交后由Streamlit加载更新。上线后侧栏应出现“电价（日前／实时）”，再用真实文件检查结果。ZIP需先解压，再上传里面的文件。

## 本地运行

```bash
python -m pip install -r requirements.txt
python -m unittest -v test_energy.py test_price.py
python -m streamlit run app.py
```

`energy.py`负责原电量功能，`price.py`负责电价识别、计算和Excel导出，`app.py`负责页面。
