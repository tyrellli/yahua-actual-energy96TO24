# 实际上网电量96点转24时段

上传电厂侧日清分账单，自动定位“省内现货日内”下的“实际上网电量”，按每连续4个15分钟电量求和为24小时，核对总量并下载Excel。

## 使用

1. 上传交易平台导出的 `.xlsx` 账单。
2. 核对识别出的结算日期和结算单元。多日期、多主体分别处理，通过下拉框选择。
3. 查看24时段结果及总量校验，下载新的Excel。

日期来自表内“结算日期”，不根据文件名猜测。不同日期和主体不混加。电量沿用原表单位，显示三位小数，汇总采用原始精度；不乘除0.25。空白电量不视为零。缺失、重复、无效数据均报错。

表头在前100行和前512列内查找，支持两级合并表头和合并为一行的完整字段名。需要“结算日期”“时段”字段，时段须为1—96。公式单元格需要Excel保存后的计算缓存。多张表若重复同一日期、主体，会提示先确认数据来源。

## 部署到Streamlit Community Cloud

将这个文件夹的内容上传到GitHub仓库根目录，至少包含 `app.py`、`energy.py`、`requirements.txt`。不要上传电厂账单。

在 https://share.streamlit.io 中点击 **Create app**，选择仓库、分支，并将入口文件设为 **app.py**。Python可选择3.12，点击部署。文件夹应展开上传，不要只上传ZIP。

若要放入已有仓库而保留现有入口，请将本程序放在独立子目录，再将新应用的入口设为该子目录下的 `app.py`。若要整合到原网页，需要将本程序页面接入原程序导航；直接覆盖原入口会替换原页面。

官方部署说明：https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/deploy

## 本地运行与测试

```bash
python -m pip install -r requirements.txt
python -m unittest -v test_energy.py
python -m streamlit run app.py
```

导出使用SUM公式，并保存已计算的缓存值。Excel包含24时段汇总、原始96点、原表单元格位置和总量校验。
